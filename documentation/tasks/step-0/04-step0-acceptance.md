# Задача 4 — Приёмка этапа 0

Этап: 0 — Каркас.
Зависимости: [задача 2](./02-http-client.md) и
[задача 3](./03-app-shell.md) (и транзитивно
[задача 1](./01-project-scaffold.md)).
Ссылка на ТЗ: [DoD раздела «Этап 0»](../../03-technical-specification.md#этап-0--каркас).

## Зачем

Задачи 2 и 3 закрывают свои тесты по отдельности и могут сойтись в одно
дерево так, что порт уже не 5173, оболочка зовёт API при открытии или
тест разбора ошибки обойдён. DoD этапа — про всё это сразу, на живом
dev-сервере. Новой функциональности здесь нет: задача либо подтверждает
стык, либо чинит расхождение стыка, не расширяя этап.

## Границы задачи

| Входит | Не входит |
|---|---|
| Прогон `lint`, `test`, `build` и ручное открытие оболочки на порту 5173 | Новый экран, логин, стор сессии — [этап 1](../../03-technical-specification.md#этап-1--сессия-сотрудника) |
| Исправление стыка, если задачи 2 и 3 не складываются в этот DoD (конфликт входа, порт, лишний запрос при старте) | Поднятие `quizbeat-srv`. Каркас в API не ходит, для приёмки сервер не нужен |
| | Смена порта, `strictPort` или базового URL «чтобы открылось» — это отступление от [задачи 1](./01-project-scaffold.md), а не способ пройти приёмку |

## ⚠ Технические нюансы и ограничения

- Если 5173 занят, `strictPort` из задачи 1 обязан уронить `npm run dev`,
  а не открыть соседний порт. Освободить 5173. Переносить порт в конфиге
  нельзя: браузер тогда ходит на origin, которого нет в
  `CORS_ORIGIN_ADMIN`.
- В сетевой панели при открытии `/` запросов на `VITE_API_BASE_URL` быть
  не должно. Запрос к `localhost:3000` на этой приёмке — ошибка стыка
  (оболочка импортировала клиент и что-то вызвала), а не повод запускать
  бэкенд.
- `npm run test` гоняется один раз по всему `src/`. Отдельный прогон
  «только новых тестов» приёмкой не считается: DoD требует, чтобы и
  монтирование оболочки, и разбор обеих форм `message` были в общем
  наборе.

## Объём работы

Чек-лист на дереве, где уже есть и клиент, и оболочка. Кода «сверх
задач 1–3» не добавлять. Если пункт не сходится — правится стык в файлах
той задачи, которая его сломала, тем же изменением.

- `npm run lint`
- `npm run test` — в выводе есть тест оболочки (заголовок «Админка
  QuizBeat») и тесты разбора `message` строкой и массивом
- `npm run build`
- `npm run dev` слушает `http://localhost:5173` и не переезжает на другой
  порт
- В браузере на `/` видна шапка «Админка QuizBeat», нет полей логина
- Неизвестный путь (например `/missing`) не белый: видна оболочка и
  пометка, что адреса нет
- В сетевой панели нет запросов к API
- Поиск по `src/` не находит вызовов `/auth/staff`

## Критерии готовности

- Все пункты чек-листа выше выполнены на одном рабочем дереве.
  Команды — по коду возврата. Экран и отсутствие запросов — ручным
  проходом в браузере на `http://localhost:5173`.
- В прогоне `npm run test` не осталось пропущенных тестов (`.skip`) на
  оболочку или разбор ошибки. Проверяется тем же прогоном.
