# Задача 5 — Удаление заметки с подтверждением

Этап: 7 — Заметки «А знали ли Вы?».
Зависимости: [задача 2](./02-notes-list.md) (строка списка); метод
`DELETE` из [задачи 1](./01-notes-store.md).
Ссылка на ТЗ: [раздел «Этап 7»](../../03-technical-specification.md#этап-7--заметки-а-знали-ли-вы)
(удаление `DELETE .../notes/:noteId`, `204`; DoD — заметка удаляется).
Карта: строка `DELETE` в
[заметках](../../02-staff-api.md#8-заметки).
Сервис —
[`NotesService.remove`](../../../../quizbeat-srv/src/notes/notes.service.ts).

## Зачем

DoD этапа требует удалить заметку с экрана. Отдельная задача не ломает
тест полного `noteIds` из задачи 4 и фиксирует отличие пустого `204`
от мягкого удаления композиции. У заметки нет файла в хранилище —
подтверждение говорит о безвозвратном удалении текста.

## Границы задачи

| Входит | Не входит |
|---|---|
| Действие «Удалить» на элементе списка: подтверждение, `DELETE .../notes/:noteId`, обновление списка | Мягкое удаление композиции — [этап 4](../step-4/05-delete-composition.md) |
| Показ `404` / иной ошибки API строкой `message` | Создание и правка — [задача 3](./03-note-form.md) |
| | Смена порядка — [задача 4](./04-notes-reorder.md) |
| | Картинки — [этап 6](../step-6/04-images-delete.md) |

## ⚠ Технические нюансы и ограничения

- Удаление жёсткое, успех — `204` без тела. Это не `200` с `deletedAt`
  как у композиции. После успеха элемент пропадает из списка
  (перечитать `GET .../notes` или убрать локально после успешного
  вызова — достаточно одного согласованного способа).
- Подтверждение — по-русски: заметка исчезнет необратимо. В
  подтверждении видны оба текста удаляемой строки (по `locale`), чтобы
  соседние заметки не путались. Отмена не вызывает `fetch`.
- `404` (нет заметки / чужая композиция / мягко удалённая композиция)
  — на блоке, без очистки сессии; список перечитать.
- Общий файл — список задачи 2. Вливать после 02; при конфликте с
  задачами 3 и 4 — после них, см.
  [README](./README.md#почему-такой-порядок).

## Объём работы

- В элементе списка: удаление с подтверждением.
- Успех → списка без этой заметки.
- Тесты:
  - согласие на удаление вызывает `DELETE` на путь с `noteId`, успех
    при `204`;
  - отмена подтверждения не вызывает `fetch`;
  - `404` показывает `message`.

## Критерии готовности

- Тесты из объёма работы проходят через `npm run test`.
- `npm run lint` проходит.
- В UI удаления заметки нет вызова `DELETE /compositions/:id`
  (удаление композиции). Проверяется чтением модуля / тестом пути.
