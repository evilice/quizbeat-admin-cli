# Задача 6 — Приёмка этапа 7

Этап: 7 — Заметки «А знали ли Вы?».
Зависимости: [задача 3](./03-note-form.md),
[задача 4](./04-notes-reorder.md) и
[задача 5](./05-notes-delete.md) (и транзитивно список из
[задачи 2](./02-notes-list.md) и стор из
[задачи 1](./01-notes-store.md)).
Ссылка на ТЗ: [DoD раздела «Этап 7»](../../03-technical-specification.md#этап-7--заметки-а-знали-ли-вы).

## Зачем

Задачи 1–5 по отдельности закрывают форму запроса и UI на моке. DoD
этапа — другой контур: на живом `quizbeat-srv` можно создать заметку с
обоими текстами, сменить порядок, поправить и удалить; запрос с одним
переводом не уходит. Без сервера стык легко остаётся зелёным в тестах
при поле `name` или частичном `noteIds`. Новой функциональности здесь
нет.

## ⚠ Технические нюансы и ограничения

- Сид `SUPER_ADMIN` — при старте сервера вне `NODE_ENV=test` и с env
  сида. Пароли в этот репозиторий не копируются. Учётка `ADMIN` тоже
  подходит: обе роли ведут заметки.
- Клиент — `http://localhost:5173`, рядом `quizbeat-srv`. Хранилище
  MinIO для этого этапа не обязательно: у заметки нет файла.
- В сети создания / правки — JSON с `translations` (`locale` +
  `text`). В сети порядка — JSON `{ noteIds: [...] }` полный набор на
  `.../notes/order`. В сети карточки при открытии — нет `GET .../full`;
  список заметок — `GET .../notes`.
- `npm run test` — один прогон по `src/`: должны быть видны тест
  «один перевод не уходит» / поле `text` и тест полного `noteIds` с
  путём `/order`. Отдельный «только приёмочный» набор DoD не закрывает.

## Объём работы

Чек-лист на дереве, где уже есть задачи 1–5. Кода сверх них не
добавлять. Если пункт не сходится — правится стык в файлах той задачи,
которая его сломала.

- `npm run lint`
- `npm run test` — в выводе есть тест формы (запрос с одним переводом
  не уходит; в теле поле `text`, не `name`) и тест, что в `noteIds`
  уходит полный текущий набор на путь с сегментом `order`
- `npm run build`
- `npm run dev` на `http://localhost:5173`, рядом запущен `quizbeat-srv`
- Вход staff → композиции → карточка существующей или новой композиции.
  В сети при открытии карточки нет `GET .../full`; блок заметок — под
  блоком картинок этапа 6
- Создание заметки с обоими текстами `ru` и `en`: в сети
  `POST .../notes` с двумя элементами `translations` (`text`), `201`,
  строка на блоке
- Попытка сохранить с одним пустым текстом: `fetch` не уходит (или
  клиент не даёт отправить)
- Смена порядка (выше / ниже): в сети `PATCH .../notes/order` с полным
  `noteIds`; повторный `GET .../notes` совпадает с экраном
- Правка одного текста: в сети `PATCH .../notes/:noteId` с обоими
  переводами; на экране актуальные тексты
- Удаление: подтверждение, в сети `DELETE` и `204`, строки нет после
  обновления списка

Композиции и заметки, заведённые только для прохода, в конце имеет
смысл удалить с экрана, если они больше не нужны.

## Критерии готовности

- Все пункты чек-листа выполнены на одном рабочем дереве. Команды — по
  коду возврата. Создание, порядок, правка, удаление — ручным проходом
  в браузере против запущенного `quizbeat-srv`, не только моком.
- В `npm run test` нет `.skip` на тесте «один перевод не уходит», на
  тесте полного `noteIds` / пути `order` и на тесте `204` удаления.
  Проверяется тем же прогоном.
