# Задача 1 — Набор 1/3/8 в разметке и списке отрезков

Этап: 10 — Набор длительностей отрезков.
Зависимости: серверный этап 15,
[задача 1](../../../../quizbeat-srv/documentation/tasks/step-15/01-clip-durations-set.md);
блок разметки — [задача 3 этапа 5](../step-5/03-waveform-and-points.md),
список отрезков — [задача 4 этапа 5](../step-5/04-clips-list-and-poll.md).
Ссылка на ТЗ: [раздел «Этап 10»](../../03-technical-specification.md#этап-10--набор-длительностей-отрезков).

## Зачем

Разметка предлагает семь длительностей, а сервер после этапа 15 примет
три. Без правки клиента менеджер выбрал бы значение, которое сервер
отклонит `400`. Заодно закрепляется: прежние отрезки с другими
длительностями не должны ломать экран.

## Границы задачи

| Входит | Не входит |
|---|---|
| `AUDIO_CLIP_DURATIONS = [1, 3, 8]` вместо семи значений; выпадающий список длительностей из неё | Изменение сервера |
| Кнопка «три точки сразу» использует ту же константу | Миграция или удаление наследованных отрезков |
| Тип `durationSec` в ответе `GET .../clips` и в списке — `number`, узкий union только у новой точки | Новые поля формы |
| Список отрезков показывает время старта, чтобы различать отрезки одной длительности и сложности | Фильтр списка по длительности |
| Короткая подсказка в блоке: «в игре используются отрезки 1, 3 и 8 секунд» | — |
| Обновить `02-staff-api.md` и разметку в ТЗ этапа 5 | — |

## ⚠ Технические нюансы и ограничения

- Значение по умолчанию длительности в форме сейчас `5`
  (`useState<AudioClipDurationSec>(5)` в `WaveformPointsBlock.tsx`) —
  станет недопустимым; поставить `1` (или первый элемент константы), не
  оставлять недопустимое значение.
- Тип `AudioClipDurationSec` сейчас используется и для новых точек, и для
  отображения отрезка (`audio-clips-store.ts`) — отрезок из ответа сервера
  с `durationSec = 5` не должен приводить к приведению типа, которое
  молча «лжёт». Развести тип точки и тип отрезка.
- Клиентская проверка «не вылезает за длительность оригинала» остаётся.
- Источник истины — сервер; рассинхрон клиентской константы с серверной
  ловится приёмкой, не рантаймом.

## Критерии готовности

- `npm run test`, `npm run lint`, `npm run build` проходят.
- Тесты на моке: выпадающий список содержит ровно 1, 3, 8; по умолчанию
  выбрано допустимое значение; «три точки сразу» добавляет точки 1, 3, 8;
  ответ сервера с отрезком `durationSec: 5` отображается в списке без
  ошибки и позволяет его удалить; два отрезка с одинаковыми длительностью и
  сложностью, но разным стартом, различимы в списке.
