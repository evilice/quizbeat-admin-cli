Этап: 7 — Заметки «А знали ли Вы?».
Зависимости: [задача 1](./01-notes-store.md) (метод списка); экран

аудио / отрезков — [этап 5](../step-5/README.md); блок картинок —
[этап 6](../step-6/README.md).
Ссылка на ТЗ: [раздел «Этап 7»](../../03-technical-specification.md#этап-7--заметки-а-знали-ли-вы)

Контроллер —
[`list`](../../../../quizbeat-srv/src/notes/notes.controller.ts).

## Зачем

Без блока на существующей карточке некуда поставить форму, порядок и
удаление. Задача фиксирует чтение `GET .../notes`, показ обоих текстов
по `locale` и место блока ниже картинок — до действий строк. Создание,
правка, порядок и удаление сюда не тащить: иначе тест списка смешается
с правилом обоих переводов и полным `noteIds`.

## ⚠ Технические нюансы и ограничения

- Блок сажается **после** блока картинок этапа 6 на том же файле
  карточки. При конфликте слияния с задачами 3–5 — эта задача
  вливается первой после стора, см.
  [порядок](./README.md#почему-такой-порядок).
- Текст берётся по полю `locale`, не по индексу массива: сервер порядок
  элементов `translations` не фиксирует. Поле — `text`, не `name`.
- Пагинации нет: ответ — массив целиком, уже в порядке `order`.
- Прямой заход на карточку без state по-прежнему идёт через стык
  этапа 4, не через `GET /full`. В сети при открытии карточки нет
  `GET .../full`; список заметок — `GET .../notes`.
- Текст заметок рисуется React-текстом, без
  `dangerouslySetInnerHTML`. Человеческое ревью этого уровня не
  требуется — см. [README](./README.md).

## Объём работы

- На карточке композиции — блок «Заметки» / «А знали ли Вы?» ниже
  блока картинок этапа 6.
- При появлении id композиции — `GET .../notes`; пустой массив —
  пустое состояние списка.
- Строка показывает оба текста (`ru` и `en`) по `locale`. Подписи
  блока — русские.
- Отказ API (`404` композиции и др.) — `message` на блоке, без очистки
  сессии.
- Тесты:
  - при монтировании / появлении id вызывается чтение списка
    `.../notes`;
  - в модуле карточки нет вызова пути `/full`;
  - пустой массив рисует пустое состояние; непустой — строки с обоими
    текстами по `locale`.

## Критерии готовности

- Тесты из объёма работы проходят через `npm run test`.
- `npm run lint` проходит.
- Ручной ориентир: на карточке под картинками виден блок; при наличии
  заметок на сервере — оба текста. Полный DoD с формой, порядком и
  удалением — у [приёмки](./06-step7-acceptance.md).
