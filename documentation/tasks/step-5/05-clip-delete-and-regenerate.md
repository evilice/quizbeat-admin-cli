## Зачем

DoD этапа требует удалить отрезок и запустить перегенерацию. Отдельная
задача не ломает тест остановки опроса из задачи 4 и фиксирует отличие
пустого `204` от `200` с телом у мягкого удаления композиции.

## Границы задачи

| Входит | Не входит |
|---|---|
| Действие «Удалить» на строке: подтверждение, `DELETE .../clips/:clipId`, обновление списка | Мягкое удаление композиции — [этап 4](../step-4/05-delete-composition.md) |
| Действие «Перегенерировать»: `POST .../regenerate`, показ обновлённого статуса, снова включить опрос при `PENDING` | Создание новых точек — [задача 3](./03-waveform-and-points.md) |
| Показ `409`, если отрезок уже `PENDING`/`PROCESSING` | Смена координат отрезка телом запроса — на сервере regenerate координаты из строки, клиент их не шлёт |
| | Картинки / заметки — [этапы 6–7](../../03-technical-specification.md#этап-6--изображения-композиции) |

## ⚠ Технические нюансы и ограничения

- Удаление жёсткое, успех — `204` без тела. Это не `200` с `deletedAt`
  как у композиции. После успеха строка пропадает из списка (перечитать
  или убрать локально после успешного вызова — достаточно перечитать
  `GET .../clips`).
- Перегенерация не принимает новое тело с точками: только id. Ответ —
  отрезок в `PENDING`; опрос из задачи 4 должен снова пойти.
- `409` `Audio clip is already pending or being processed` — на блоке /
  строке, без очистки сессии. Кнопку перегенерации на уже
  `PENDING`/`PROCESSING` лучше не предлагать или сразу показать отказ.
- Подтверждение удаления — по-русски: отрезок исчезнет необратимо.
  Отмена не вызывает `fetch`.
- Общий файл — список задачи 4. Вливать после 04.

## Объём работы

- В строке списка: удаление с подтверждением; перегенерация для
  терминальных статусов (`DONE`, `FAILED`).
- Успех удаления → список без этой строки; успех regenerate → статус
  `PENDING` и опрос снова активен.
- Тесты:
  - согласие на удаление вызывает `DELETE` на путь с `clipId`, успех при
    `204`;
  - отмена подтверждения не вызывает `fetch`;
  - regenerate — `POST` на `.../clips/:clipId/regenerate` без тела точек;
  - `409` показывает `message`.

## Критерии готовности

- Тесты из объёма работы проходят через `npm run test`.
- `npm run lint` проходит.
- В UI удаления отрезка нет вызова `DELETE /compositions/:id` (удаление
  композиции). Проверяется чтением модуля / тестом пути.
