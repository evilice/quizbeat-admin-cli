# QuizBeat — клиент админки

Веб-клиент админки музыкальной игры-угадайки QuizBeat. Сотрудники ведут
композиции, отрезки, теги, картинки и заметки через уже готовый API
[quizbeat-srv](../quizbeat-srv). Подробнее — в [документации](./documentation).

Каталог репозитория называется `quizbeat-admin-cli`. Это имя папки, не тип
приложения: клиент — сайт на React, не командная утилита.

## Документация

Нумерация документов этого репозитория своя и идёт подряд. Этапы поставки
тоже свои: это не номера этапов сервера.

- [Обзор](./documentation/01-project-overview.md) — кто пользуется клиентом,
  какие сценарии он закрывает, как он связан с сервером.
- [Staff-API](./documentation/02-staff-api.md) — карта вызовов, ролей и
  ловушек контракта, на которую опираются экраны. Поля DTO сверяются с
  кодом `quizbeat-srv`, карта их целиком не копирует.
- [Техническое задание по этапам](./documentation/03-technical-specification.md) —
  стек, общие требования, порядок поставки экранов, принятые по умолчанию
  решения. Сессия и сотрудники идут сразу после каркаса, чтобы в приложение
  можно было войти и проверять его руками.
- [Правила разработки](./documentation/04-development-rules.md) — обязательные
  практики для написания кода через вайб-кодинг. Адаптация правил бэкенда.
- [Оформление задач](./documentation/tasks/task-writing-guidelines.md) —
  как декомпозировать этап ТЗ на файлы в `documentation/tasks/step-N/`.
  Этапы 0–2 разобраны в
  [documentation/tasks/step-0](./documentation/tasks/step-0/README.md),
  [step-1](./documentation/tasks/step-1/README.md),
  [step-2](./documentation/tasks/step-2/README.md).

Схема таблиц сервера — в
[модели данных бэкенда](../quizbeat-srv/documentation/02-data-model.md).
Клиент на неё не опирается напрямую: рабочий контракт — карта выше.

Каркас Vite и HTTP-клиент этапа 0 собраны. Оболочка — следующая задача
того же этапа. После `npm install`:

| Что | Команда |
| --- | --- |
| dev-сервер | `npm run dev` |
| тесты | `npm run test` |
| линт | `npm run lint` |
| формат | `npm run format` |
| сборка | `npm run build` |

## Локальная связка с сервером

Сервер: `http://localhost:3000`. Клиент: `http://localhost:5173` — этот
origin уже разрешён в `CORS_ORIGIN_ADMIN` бэкенда. Если порт занят,
dev-сервер останавливается и не переезжает на другой.
