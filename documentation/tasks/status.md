## Исправления по полному ревью `src` (4 октября 2026)

Исправлено: `401` без refresh-токена завершает сессию (`onAuthLost`);
выход во время refresh не возвращает токены; нечитаемый access из логина и
refresh даёт `ApiError`, `setPair` бросает; поздний `401` после чужой
ротации повторяется без второго refresh; обрыв тела ответа даёт `ApiError`
без статуса; экраны композиций и сессии берут тексты через
`messagesFromError`; presigned-ссылки отрезков и превью обновляются не чаще
раза в 60 с (`useAttemptThrottle`), а не раз за жизнь вкладки; теги для
выбора грузятся со всех страниц, ошибка загрузки показывается; повторная
загрузка трека той же длительности перезапрашивает ссылку волны; поиск
тегов и композиций с задержкой (`SEARCH_DEBOUNCE_MS`); поля из одних
пробелов не проходят проверку, значения уходят обрезанными.

Общее состояние списка (страница, запрос, устаревшие ответы, ошибка списка,
перечитывание после `404`) вынесено в `shared/hooks/use-list-query.ts` и
используется списками сотрудников, тегов и композиций; фильтры и действия
над строками остались в экранах.
